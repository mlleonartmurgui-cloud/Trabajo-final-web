# Proyecto Final de 1.º de Bachillerato

Este sitio web ha sido desarrollado como proyecto académico para el curso de 1.º de Bachillerato, con fines exclusivamente educativos y sin ánimo de lucro.

Los personajes, imágenes, nombres y elementos relacionados con el universo de Nintendo utilizados en esta página pertenecen a sus respectivos propietarios. Su uso tiene como único propósito ilustrar y enriquecer el contenido del proyecto.

Este sitio no está afiliado, patrocinado ni respaldado por Nintendo. Si algún titular de derechos considera que algún contenido debe ser modificado o retirado, puede ponerse en contacto con el autor del proyecto.

Gracias por visitar la página y dedicar unos minutos a explorar este trabajo.
